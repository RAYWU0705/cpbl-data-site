# v5.6.1-C 安全搬移指南

## 這次會搬什麼

```txt
data-quality.html
→ ops/data-quality.html

teams-dashboard.html
→ ops/teams-dashboard.html

live-logger.html
→ ops/live-logger.html

admin-live-debug.html
→ admin/ops-center.html

admin-manual-override.html
→ local-tools/manual-override.html
```

`game-day.html` 保留在根目錄，因為它也是公開的今日戰情頁。

## 安全設計

- 預設只 dry-run。
- 必須加 `--write` 才會搬移。
- 搬移前自動備份。
- OPS 與 ADMIN 舊網址會留下轉址頁。
- LOCAL TOOL 不留公開轉址。
- 自動修正 CSS、JS、圖片、JSON、HTML 連結。
- 更新 `config/pages.json`。
- 加入 `local-tools/` 到 `.gitignore`。
- 建立 `ops/index.html`、`admin/index.html`。
- 提供 rollback 腳本。

## 第一步：語法檢查

```powershell
node --check scripts/migrate-page-architecture.js
node --check scripts/rollback-page-architecture.js
```

## 第二步：預覽

```powershell
node scripts/migrate-page-architecture.js
```

這一步不會修改任何檔案。

## 第三步：正式搬移

```powershell
node scripts/migrate-page-architecture.js --write
```

## 第四步：檢查

```powershell
node scripts/check-page-structure.js
node scripts/plan-page-moves.js
git status --short
```

## LOCAL TOOL 的 Git 處理

`local-tools/` 會加入 `.gitignore`，但原本的
`admin-manual-override.html` 已被 Git 追蹤。

搬移後請不要使用 `git add -A`。

等確認本機工具正常後，使用：

```powershell
git add -u admin-manual-override.html
```

這只會記錄舊公開檔案的刪除，不會把 `local-tools/` 加入 Git。

## 回復

正式搬移完成後，終端會顯示備份資料夾，例如：

```txt
scripts\backup\page-architecture-20260611-150000
```

回復指令：

```powershell
node scripts/rollback-page-architecture.js --backup=page-architecture-20260611-150000
```
