# v5.6.1-D ROUTE-SAFE PATH SYSTEM

## 新增檔案

```txt
js/site-root.js
scripts/install-site-root-system.js
scripts/check-relative-path-risks.js
```

## 1. 語法檢查

```powershell
node --check js/site-root.js
node --check scripts/install-site-root-system.js
node --check scripts/check-relative-path-risks.js
```

## 2. 預覽安裝

```powershell
node scripts/install-site-root-system.js
```

預設不修改 HTML。

## 3. 正式安裝到登錄頁面

```powershell
node scripts/install-site-root-system.js --write
```

會自動備份 HTML 到：

```txt
scripts/backup/site-root-install-時間/
```

## 4. 掃描外部 JS 相對路徑風險

```powershell
node scripts/check-relative-path-risks.js
```

嚴格模式：

```powershell
node scripts/check-relative-path-risks.js --strict
```

## 使用方式

```js
const liveUrl = window.CPBLSiteRoot.url(
  "data/live/live-boxscore.json"
);

const logoUrl = window.CPBLSiteRoot.url(
  "assets/logo/brothers.png"
);

const matchUrl = window.CPBLSiteRoot.url(
  "match.html?gameSno=147"
);

const data = await window.CPBLSiteRoot.fetchJson(
  "data/live/live-boxscore.json"
);
```
