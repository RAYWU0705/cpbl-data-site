# v5.6.1-B 使用順序

## 1. 先預覽 Metadata

```powershell
node scripts/apply-page-metadata.js --dry-run
```

這一步不修改 HTML。

## 2. 正式加入 Metadata

確認預覽正常後：

```powershell
node scripts/apply-page-metadata.js
```

腳本會先備份原始 HTML 到：

```txt
scripts/backup/page-metadata-時間/
```

重複執行不會重複加入註解；已存在時會更新。

## 3. 再跑頁面結構檢查

```powershell
node scripts/check-page-structure.js
```

原本的 26 個「尚未加入 Page Metadata」資訊應該消失。

## 4. 掃描搬移風險

```powershell
node scripts/plan-page-moves.js
```

這一步只分析，不搬檔、不修改檔案。

只看某一類：

```powershell
node scripts/plan-page-moves.js --only=LOCAL_TOOL
node scripts/plan-page-moves.js --only=ADMIN
node scripts/plan-page-moves.js --only=OPS
```

只看某個檔案：

```powershell
node scripts/plan-page-moves.js --only=admin-manual-override.html
```

JSON 輸出：

```powershell
node scripts/plan-page-moves.js --json
```

## 本版不會做的事

- 不搬 HTML。
- 不改網址。
- 不改 CSS。
- 不改 JS。
- 不改 JSON。
- 不改 Git。
